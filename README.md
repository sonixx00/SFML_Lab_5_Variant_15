Лабораторна робота №5

Тема: Використання SFML в C++ проєкті. Використання пакетного менеджера vcpkg.

Варіант 15: Рух частинки в гравітаційному полі центрального тіла.

Мета роботи

Отримати практичні навички створення та налаштування C++ проєкту у Visual Studio з використанням бібліотеки SFML, системи складання CMake та пакетного менеджера vcpkg.

Опис програми

Розроблена програма моделює рух частинки навколо нерухомого центрального тіла під дією гравітаційної сили, величина якої залежить від відстані між тілами.

У графічному вікні відображаються:
 • Центральне тіло (жовте коло).
 • Рухома частинка (блакитне коло).
 • Траєкторія руху частинки (блакитна лінія).

Програма дозволяє змінювати початкову швидкість і початкову відстань частинки від центрального тіла та досліджувати їхній вплив на траєкторію руху.

Використані технології
 • Мова програмування C++.
 • Бібліотека SFML 3.1.0.
 • Visual Studio 2022.
 • CMake.
 • vcpkg.
Запуск проєкту
 1. Встановити Visual Studio з підтримкою C++ та CMake.
 2. Встановити пакетний менеджер vcpkg.
 3. Налаштувати шлях до vcpkg у файлі CMakePresets.json.
 4. Відкрити папку проєкту у Visual Studio.
 5. Виконати конфігурацію та збирання проєкту.
 6. Запустити створений виконуваний файл.

Результати дослідження

Під час виконання лабораторної роботи було перевірено рух частинки за різних початкових умов.

Встановлено, що зміна початкової швидкості та відстані до центрального тіла впливає на форму й розміри траєкторії. За певних значень параметрів частинка рухається замкненою орбітою, а за інших може віддалятися від центрального тіла або наближатися до нього.

Висновок

У результаті виконання лабораторної роботи було створено C++ програму з використанням SFML для моделювання руху частинки в гравітаційному полі центрального тіла. Реалізовано графічне відображення руху, побудову траєкторії та можливість зміни початкових умов. Досліджено вплив початкової швидкості та положення частинки на характер її руху.
